# Industrial Video Time Study Analyst App

A web application that uses Google Gemini Vision models to automatically analyze manufacturing videos and perform industrial time studies, identifying value-added/non-value-added activities, cycle times, bottlenecks, and ergonomic insights.

## Features
- **Video Ingestion**: Upload local manufacturing videos (MP4, MOV, AVI).
- **Gemini Vision Integration**: Queries `gemini-1.5-pro` or `gemini-2.5-flash` with a detailed time study prompt.
- **Interactive Dashboard**:
  - **KPI Cards**: Displays productivity score, cycle times, and value-added percentages.
  - **Interactive Gantt Timeline**: Displays activities on a timeline chart (using Plotly).
- **Detailed PDF/Markdown Reports**: Full textual report generated by the AI detailing bottlenecks and recommendations.
- **Demo Mode**: Built-in mock study dataset so you can preview the dashboard layout without an API key immediately.

## Setup Instructions

### Prerequisites
- Python 3.9 or higher installed.

### Installation
1. Navigate to the project folder:
   ```bash
   cd "/Users/aswin/pricol_video ingestion"
   ```
2. Create a virtual environment:
   ```bash
   python3 -m venv venv
   ```
3. Activate the virtual environment:
   - On macOS/Linux:
     ```bash
     source venv/bin/activate
     ```
   - On Windows:
     ```cmd
     venv\Scripts\activate
     ```
4. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Run the Application
1. Launch the Streamlit server:
   ```bash
   streamlit run app.py
   ```
2. The app should automatically open in your default browser at `http://localhost:8501`.

## How to Get a Google Gemini API Key

To use the live video analysis feature, you need a Google Gemini API key. Here is how to acquire one:

1. **Go to Google AI Studio**: Visit [https://aistudio.google.com/](https://aistudio.google.com/).
2. **Sign In**: Log in using any Google / Gmail account.
3. **Get API Key**: Click on the **"Get API key"** button in the left navigation sidebar.
4. **Create Key**: Click **"Create API key"**. You can choose to:
   - Create it in a new Google Cloud project.
   - Create it in an existing Google Cloud project.
5. **Set Up Billing (Optional but Recommended for Large Videos)**:
   - By default, you start on the **Free Tier**, which allows up to 15 RPM (Requests Per Minute) and 1 million TPM (Tokens Per Minute), which is sufficient for small testing.
   - If you plan to upload videos larger than a few megabytes or need higher limits, click **"Set up billing"** in AI Studio to enable Pay-As-You-Go pricing.
6. **Copy the Key**: Copy the generated API key string and paste it into the sidebar of the Streamlit application.
